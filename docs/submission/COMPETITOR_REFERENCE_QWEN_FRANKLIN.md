## Influence On This Submission

Myles's Founding Father A.I. influenced The Social Engine by framing a useful question for the artifact: what changes when AI is not only used to help build a project, but is also placed inside the project as an interactive intelligence or character?

The Social Engine keeps that influence visible through a credited, fictional guest signal about provenance, media literacy, context collapse, and friendly competition.
