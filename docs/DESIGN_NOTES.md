# Design Notes

## Theme Fit

The Social Engine: Context Collapse treats early and modern social media as an independence engine. It shows how the internet let people in small places find Linux mentors, coding peers, golf advice, local events, retro computer collectors, and strange hobby groups without needing old geographic or institutional gatekeepers.

The same engine can turn into a feed machine. Reach, drama, family weirdness, algorithm heat, and context collapse create pressure against trust and agency.

## Fictional Platform

The in-game service is SignalBarn, an original fictional platform. It uses old-web dashboard flavor, profile cards, graph nodes, feed cards, and notification-like panels without copying any real social network.

No real platform names, logos, layouts, or trademarked visual references are used.

## Core Loop

Each run lasts 30 days.

1. Choose one action.
2. Apply direct meter, follower, and relationship effects.
3. Trigger a feed event, viral event, or context collapse.
4. If fallout occurs, choose a response.
5. Advance the day and check victory/failure.

## Meter Intent

- Reach rewards growth but increases exposure.
- Trust protects close ties and credibility.
- Agency measures real-world opportunity and independence.
- Belonging measures support and community health.
- Drama and Burnout are pressure meters.
- Algorithm Heat controls escape velocity.
- Reality Drift tracks rabbit-hole pull.
- Skill Cred supports Knowledge and Creator paths.

## Followers Are Not Generic

Followers are split into categories because the game should not reward raw audience size blindly. Losing drama followers can improve a run. Losing close friends can trigger failure.

## Victory And Failure

Multiple victory paths are calculated from the final state. Hybrid titles are possible when multiple paths qualify. Failures can occur early if trust, burnout, drama, reality drift, or relationship health collapse.

## v0.1 Art Direction

The build uses CSS, original vector UI, and a custom SignalBarn mark. It does not use external copyrighted art. The look aims for nostalgic forum/dashboard energy rather than a clone of any existing platform.
