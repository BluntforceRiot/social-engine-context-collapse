# Submission Notes

## Project Title

The Social Engine: Context Collapse

## Short Description

A fictional card-and-graph strategy sim where you use SignalBarn to find your people, build community, survive virality, and avoid context collapse across a 30-day online life.

## Theme Connection

Summer into AI Week 2: Independence Engines.

The internet gave people independence from geography and old gatekeepers. Then the feed became a new engine of reach, belonging, argument, and dependency.

## What It Is About

This is about social media dynamics, old internet community discovery, context collapse, virality, relationship maintenance, weird relatives, niche communities, and the feed as an engine.

## What It Is Not

This is not a party-politics simulator. It does not use real politicians, real political parties, direct partisan conflict, real platform branding, real social network layouts, or trademarked platform visuals.

## Proof Notes

- Static Vite + TypeScript browser game.
- No backend, login, analytics, tracking, or network calls.
- Local run history only.
- Fictional platform and fictional characters.
- Original SVG/CSS/HTML visuals only.
- Generated WebAudio only; no copyrighted audio.
- GitHub Pages workflow included but not deployed/pushed by Codex.
- v0.3 automated playtests cover three 30-day strategy styles: balanced repair/community, creator/viral pressure, and community organizer.

## Scoring Notes

The scoring model rewards balanced reach, trust, agency, belonging, skill credibility, opportunity contacts, community health, relationship repair, and real-world organizing. It penalizes drama, burnout, reality drift, trust collapse, and excessive drama-follower accumulation.
