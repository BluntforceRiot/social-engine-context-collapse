# Submission Notes

## Project Title

The Social Engine: Context Collapse

## Short Description

A fictional card-and-graph strategy sim where you use SignalBarn to find your people, build community, survive virality, and avoid context collapse across a 30-day online life.

## Theme Connection

Summer into AI Week 2: Independence Engines.

The project frames social media as an independence engine: it can free people from geography and gatekeepers by connecting them to niche knowledge, friendship, opportunity, and local organizing. It can also create a new dependency engine through virality, context collapse, drama, burnout, and feed pressure.

## Proof Notes

- Static Vite + TypeScript browser game.
- No backend, login, analytics, tracking, or network calls.
- Local run history only.
- Fictional platform and fictional characters.
- No real political parties, real politicians, real platform branding, or real social network UI clones.
- Original SVG/CSS/HTML visuals only.
